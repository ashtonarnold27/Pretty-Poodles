# 🐩 Pretty Poodles

A simple, responsive landing page for our family's poodle puppies.

## Structure
- `index.html` — the whole site (single-page landing).
- `css/styles.css` — all styling, mobile + desktop responsive.
- `js/main.js` — puppy data + interactivity (cards & modal).
- `images/` — put puppy and parent photos here.

## How to edit puppies
Open `js/main.js` and edit the `puppies` array. For each puppy you can set:
name, photo, estimatedSize, description, and mom/dad (name, photo, size).

## Running locally
Just open `index.html` in your browser. No build tools needed.

## Deploying (free) with GitHub Pages
1. Push to GitHub.
2. Repo Settings → Pages → Source: `main` branch, `/root`.
3. Your site goes live at `https://YOUR-USERNAME.github.io/pretty-poodles/`
